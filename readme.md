# AgroFuturo 2026

## Tema da Página
Agricultura Familiar, Tecnologia, Inteligência Artificial e Sustentabilidade.

---

## Objetivo da Página

Apresentar de forma moderna, futurista e acessível a importância da agricultura familiar no Brasil, destacando:

- desafios da mecanização agrícola;
- acesso a máquinas e equipamentos;
- políticas públicas de incentivo;
- uso de inteligência artificial;
- automação rural;
- previsão de eventos climáticos;
- inovação tecnológica aplicada ao campo.

---

## Recursos Implementados

- Hero Section moderna
- Layout responsivo (320px até 2560px)
- Cards informativos
- Accordion com JavaScript
- Formulário de inscrição
- Área de comentários
- Espaços reservados para 3 imagens
- Caixa flutuante de acessibilidade
- Aumento e redução de fonte
- Alternância entre modo claro e escuro
- Leitura por voz com SpeechSynthesis API
- Design futurista com visual tecnológico
- CSS Grid e Flexbox
- HTML semântico
- JavaScript separado

## Instruções de Uso

1. Salve os arquivos:
   - index.html
   - style.css
   - script.js

2. Coloque as imagens na mesma pasta:
   - Foto1.png
   - Foto2.png
   - Foto3.png

3. Abra o arquivo index.html em qualquer navegador moderno.

4. Utilize a caixa de acessibilidade para:
   - aumentar fonte;
   - diminuir fonte;
   - alternar tema claro/escuro;
   - iniciar leitura por voz;
   - parar leitura.
